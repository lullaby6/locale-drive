A Google Drive for your local network

Share a folder from your computer and open it from any phone, tablet or laptop on the same Wi-Fi. Browse, upload, download and organize files from the browser: no accounts, no cloud, nothing to install on the other devices.

One computer shares, every device opens it

Locale Drive is not a send-to-device app. Your computer becomes a small file server for one folder, and any device on the network opens it like a website.

Your computer

Runs Locale Drive and shares one folder. Files stay on its disk.

Same Wi-Fi / LAN

Everything travels over your local network, at its full speed.

Any device

Phones, tablets, laptops, TVs... they only need a web browser.

How it works

Three steps, zero configuration.

  1. 1

    Start Locale Drive

    Open the desktop app, or run npx locale-drive in a terminal. It opens the shared folder in your browser.

  2. 2

    Scan the QR code

    Click Connect another device and scan the code with your phone, or type the address it shows.

  3. 3

    Share files

    Upload, download, preview, move and organize files from any device. Changes show up everywhere at once.

Features

Everything you expect from a file explorer, in the browser of every device.

Folders and breadcrumbs

Create folders, browse them with breadcrumbs and go back with the browser button.

Drag and drop

Drop files anywhere to upload them, or onto a folder. Drag items onto folders to move them.

Selection like your explorer

Box selection, Shift+click ranges, checkboxes, and Ctrl/Cmd to add to the selection.

Keyboard shortcuts

Ctrl+A, arrows, Enter, Backspace, Delete, F2 and more. Press ? in the app to see them all.

List and grid layouts

Rows with details, or a grid with thumbnails. Your choice is remembered.

Previews

Images, video, audio, PDFs and text or code files open in a full-screen viewer.

Bulk downloads

Download several files or whole folders as a single .zip, or delete them together.

Upload progress

Speed, time left and a cancel button for every upload.

Live updates

Changes from any device, or made directly in the folder, appear everywhere without reloading.

Shared clipboard

Paste text or a link on one device and copy it on another.

Connect with a QR code

Shown in the terminal and in the app, so phones connect in seconds.

Works without internet

Everything, icons included, is served by your computer. Perfect for an offline LAN.

Resumable downloads

HTTP range requests let downloads resume and videos seek.

Storage info

Number of files and folders, space used and free disk space.

English and Spanish

Picked from the device language, and switchable from the header.

Light, dark and device themes

Follows your system or the theme you pick.

About the desktop app

  • Requires Windows 10 or 11. Node.js is included, you don't need to install it.
  • The first time it opens, Windows Firewall asks whether node may use the network: allow it on private networks, or other devices won't be able to connect.
  • Files are stored in Documents\Locale Drive.
  • Click the tray icon to open the page again. Right click → Exit stops the server.
All releases and changelog

Install with npm

Works on Windows, macOS and Linux. Requires Node.js 22.12 or newer.

1

Install it globally

Adds the locale-drive command to your terminal.

$ npm install -g locale-drive
2

Share a folder

Prints the LAN address and a QR code, and opens the app in your browser.

$ locale-drive /path/to/folder
3

Or run it without installing

npx downloads and runs the latest version.

$ npx locale-drive /path/to/folder

If you don't pass a path, Locale Drive uses ./storage in the current directory and creates it if needed.

Terminal 
$ npx locale-drive
Storage path: C:\Users\you\Documents\Locale Drive
Server listening on: http://192.168.1.20:24680

Options

Option Alias Default Description
--port -p 24680 Port the server listens on.
--max-upload -m 0 Max size per uploaded file, in MB. 0 means no limit.
--no-open Don't open the browser on start.
--help Show all options.

Examples

# Share ~/Videos on port 8080 $ locale-drive ~/Videos --port 8080
# Limit uploads to 500 MB per file and don't open the browser $ locale-drive ./shared -m 500 --no-open

Ports

Port 24680 is used by default. If it's taken, the next free port is used, and the terminal, the QR code and the app always show the port in use. If you pass --port and it's taken, Locale Drive stops with a message instead.

Only on networks you trust

Anyone on your network who opens the address can read, upload, move and delete files in the shared folder. Run Locale Drive at home, in the office or on your own hotspot, not on public Wi-Fi.

Frequently asked questions

Is it free?

Yes. Locale Drive is free and open source under the MIT license. No ads, no tracking, no accounts.

Do the other devices need to install anything?

No. Only the computer that shares the folder runs Locale Drive. Phones, tablets and other computers just open the address in a web browser.

Does it work over the internet?

No, and that's on purpose. It works between devices connected to the same Wi-Fi or local network, and keeps working if that network has no internet access.

Where are my files stored?

In the folder you share, on the computer running Locale Drive. The desktop app uses Documents\Locale Drive; with npm you choose the folder. Nothing is uploaded to any cloud.

How is it different from file-sending apps?

Send-to-device apps push files from one device to another, and every device needs the app. Locale Drive shares a folder that every device can browse at the same time from a browser, like a small Google Drive on your LAN.

Other devices can't connect. What do I check?

Make sure they're on the same network, that Windows Firewall allows node on private networks, and that you're using the address or QR code shown by the app (the port may change if 24680 is taken).

Is there a size limit for files?

No limit by default. With npm you can set one per file with --max-upload (in MB).
